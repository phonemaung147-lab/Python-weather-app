# Python-weather-app
# 東京の天気情報取得プログラム

## 1. 概要

Open-Meteo APIを利用して、東京の現在の気温と天気コードを取得し、画面に表示するPythonプログラムです。

## 2. 使用技術

* Python
* Requestsライブラリ
* Open-Meteo API

## 3. 主な機能

* 天気情報の取得
* 現在の気温の表示
* 天気コードの表示
* エラー発生時のメッセージ表示

## 4. 工夫した点

APIから取得したJSONデータから必要な情報を取り出し、気温と天気コードを分かりやすく表示するようにしました。

## 5. 実行方法

Requestsライブラリをインストールしてから、次のコマンドで実行します。

```bash
pip install requests
python weather.py
```

## 6. 今後の改善点
